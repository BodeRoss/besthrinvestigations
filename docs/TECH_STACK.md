# Technology stack

No packages have been installed. No framework has been initialized. Nothing in the proposed list is a commitment.

## Confirmed

These are in use or explicitly chosen for the site itself.

| Technology | Role |
| --- | --- |
| HTML | Page structure and content |
| CSS | Presentation and responsive layout |
| JavaScript | Browser behavior, only where HTML and CSS are not enough |
| Git | Version history for this repository |
| Markdown | Project documentation in `docs/` |

The site is authored as plain files. There is no package manager, bundler, compiler, or framework on the confirmed list.

## Proposed

These are options only. They are not installed, not configured, and not approved.

| Proposal | Why it is only a proposal |
| --- | --- |
| Static file hosting | The site is static, but the host is not chosen. See `DEPLOYMENT.md`. |
| A local static file server for preview | Optional convenience while editing. Opening HTML files directly is enough to start. No server is set up. |
| Self-hosted font files in `public/fonts/` | Possible if brand fonts must ship with the site. No fonts have been added. System fonts are sufficient until a brand decision exists. |

## Explicitly not in the stack

The following are not part of this project unless a requirement is demonstrated and the addition is approved:

- Backend language or server framework
- Database
- CMS
- Authentication
- CSS or JavaScript frameworks and UI kits
- Build tools and package dependencies
- Analytics, chat widgets, form backends, CDNs, and other external services

If any of those are approved later, add them to the confirmed table in this file and record the reason in `DECISIONS.md` before use.
