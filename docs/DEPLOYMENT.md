# Deployment

Hosting, DNS, HTTPS, and the deployment process are **pending**. Nothing has been chosen or created.

## Not decided

- Where the static files will be hosted
- The public domain name
- Which DNS provider will point that domain at the host
- How HTTPS certificates will be issued and renewed
- How a person publishes an update (manual upload, Git-based publish, or another method)
- Who is allowed to publish

## Constraints that already apply

Until a deployment decision is accepted and written in `DECISIONS.md`:

- Do not create hosting accounts, DNS records, certificates, or pipelines.
- Do not add a backend or a third-party service in order to "make deployment easier."
- Keep the site as files that can be copied to any static host later.

When a host is chosen, replace this placeholder with the actual steps a person can follow without Cursor or other AI tools: what to upload, where it goes, how to check that the live site matches the repository, and how HTTPS is confirmed.
