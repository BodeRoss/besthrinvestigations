# Project overview

## Purpose

This project is the public website for **Best Human Resources Consulting and Investigations**, operated by Diane Ross.

The site gives visitors clear information about the firm's services:

- HR Consulting
- Workplace Investigations
- Consultations

The goal is a professional, accessible, responsive business website. It should be straightforward to read, easy to use on phones and desktops, and possible to update without specialized tooling.

## What this repository is for

This repository holds the website source and the project documentation. All source code stays here. The site is intended to be a small, static frontend.

## What this repository is not

This project does not include a backend, database, content management system, user accounts, or third-party services. Those are out of scope unless a later, documented requirement shows they are necessary and they are explicitly approved.

## Current status

Repository setup and Git are in place. Website design, page content, and hosting are not started. See `PROGRESS.md` for the stage list and `DECISIONS.md` for the constraints that guide the work.
